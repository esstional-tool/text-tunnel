# Text Tunnel 폰 (안드로이드 에이전트 앱)

PC 의 메신저 앱 → **원격 화면 보기** 에서 이 폰 화면을 보고 **터치·글자·뒤로·홈**으로 조종하게 해 주는 작은 앱입니다.
서버(`/api/remote/*`)와 PC 보는 화면은 **PC 에이전트와 같은 구조를 그대로 재사용**하고, 이 앱은 폰 쪽 에이전트 역할만 합니다 (이슈 #46).

```
[폰: 이 앱] ── 프레임(JPEG) / 입력 수신(SSE) ──▶ [서버] ◀── [PC 브라우저: 원격 화면 보기 + 폰 도구줄]
 · 화면 캡처   MediaProjection (안드로이드가 허용 창을 띄움)
 · 터치 주입   접근성 서비스 dispatchGesture (탭·길게·스와이프) + 뒤로/홈/최근/알림 + 글자 입력
 · PIN         폰 주인이 정하고 폰이 직접 확인 (PBKDF2 해시, 서버는 중계만)
```

외부 라이브러리 없이 안드로이드 기본 API + Kotlin 만 씁니다. 서버·PC 쪽과 같은 원칙입니다 (DB·외부 서비스 없음, 화면·입력 내용 기록 안 함).

## 쓰는 방법 (폰)
1. **앱 설치**: `app-debug.apk`(또는 release) 를 폰에 설치 — "알 수 없는 앱 설치"를 허용해야 합니다.
2. **서버**: 기본은 `https://text-tunnel.onrender.com` (내 서버를 쓰면 주소를 바꿈)
3. **짝 맺기**: PC 의 메신저 앱 메뉴 → *새 기기 연결* 의 6자리 코드를 입력 (5분·1회용)
4. **접속 PIN 정하기**: 이 PIN 을 아는 사람만 폰 화면을 볼 수 있습니다. 정하기 전에는 아무도 못 봅니다
5. **화면 공유 켜기**: 안드로이드 허용 창에서 *지금 시작*. 켜져 있는 동안 **알림이 항상 떠 있고** 알림의 *중지*로 끌 수 있습니다
6. (선택) **조종 허용**: 접근성 서비스를 켜야 합니다 — 설정 → 접근성 → 설치된 앱 → *Text Tunnel 폰 조종*. 안드로이드 13 이상은 앱 정보 → ⋮ → *제한된 설정 허용*을 먼저 해야 켤 수 있습니다. 그다음 앱의 *조종 허용* 스위치를 켭니다
7. **PC 에서**: 메신저 앱 메뉴 → *PC 원격 연결* → *원격 화면 보기* → PIN 입력 → *조종 켜기* → 폰 도구줄(뒤로·홈·최근·알림·글자 보내기)이 나타납니다

PC 입력은 이렇게 폰 터치로 바뀝니다: 마우스 클릭 = 탭 (0.5초 넘게 = 길게 누르기) · 드래그 = 스와이프 · 휠 = 스크롤 · **오른쪽 버튼 = 뒤로** · 가운데 버튼 = 홈 · 키보드 글자 = 입력칸에 입력 · **한글은 "폰에 글자 보내기" 칸**.

## 안전장치
- 화면 공유 중 **알림이 항상 떠 있음** (+ 안드로이드의 화면 공유 표시). 누가 보기 시작하면 팝업 알림
- **PIN 필수**(폰이 직접 확인, 5번 틀리면 10분 잠금). 서버는 PIN 을 저장하지 않음
- **조종은 별도 허용(기본 꺼짐)**, 접근성 서비스는 사용자가 설정에서 직접 켬. 알림의 *조종 끄기*로 즉시 끌 수 있음
- 보는 사람이 없으면 화면을 찍지도 보내지도 않음. 화면이 안 바뀌면 보내지 않음
- 접속 성공·실패·조종 시작/끝은 앱 전용 저장 공간의 `access.log` 에 (PIN·열쇠·화면·입력 내용은 기록 안 함)
- 은행 앱 등 보안 화면(FLAG_SECURE)은 안드로이드가 검게 처리합니다 (그대로 둠)

## 빌드
Android Studio 에 들어 있는 JDK·SDK 를 씁니다 (Windows).
```
cd android
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-21.0.10.7-hotspot
set ANDROID_HOME=C:\Users\<사용자>\AppData\Local\Android\Sdk
gradlew.bat assembleDebug        # app\build\outputs\apk\debug\app-debug.apk
```
디버그 빌드는 같은 PC 의 로컬 서버(http)에도 연결할 수 있고(에뮬레이터는 호스트를 `10.0.2.2` 로 봄), 시험용 단추·로그가 들어 있습니다. 배포용(release)은 https 만 허용합니다.

## 폰 원격 시험 (가상 폰)
`tests/phone-agent.test.js` 는 에뮬레이터에 앱을 설치해 서버·보는 쪽과 끝까지 확인합니다 (프레임 수신, 탭·길게·스와이프·스크롤·글자·뒤로·홈, 조종 끄기, 알림·기록).
```
# 1회: 시스템 이미지(Android 14, Google APIs x86_64)를 SDK 의 system-images 에 설치하고 AVD "tt-test" 를 만든다
emulator -avd tt-test -no-window -no-audio -gpu swiftshader_indirect -no-snapshot   # 부팅 후
node server.js
node tests/phone-agent.test.js http://localhost:8787
```
이 시험은 **에뮬레이터 전용**입니다 (앱 설정·접근성·터치를 바꿈). 실제 폰이 연결돼 있어도 에뮬레이터만 고릅니다.

## 설치·연결 (이슈 #48)

폰의 text-tunnel 메뉴 → **휴대폰 원격 연결하기** 를 누르면 앱이 있으면 열리고(자동 짝 맺기), 없으면 APK 가 내려받아집니다. 직접 링크는 `texttunnel://connect?code=<6자리>&server=<주소>`. 릴리스 APK 는 `build-release.cmd` 로 만들어 `public/download/` 에 둡니다(서명 키는 `~/.android/text-tunnel-release.jks`).
