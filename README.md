## 기능

### 1. 연결
- **QR 짝 맺기** — PC에서 "QR 띄우기" → 휴대폰 기본 카메라로 찍으면 연결. QR이 안 되면 **6자리 코드** 입력 (5분·1회용)
- **자동 연결** — 한 번 짝 맺으면 다음부터는 앱만 열면 바로 연결
- **둘만** — 내 PC + 내 휴대폰, 최대 2대 (3번째 기기는 못 들어옴)
- **다시 연결** — 상대를 기다리는 화면에 QR이 항상 떠 있어서 연결이 풀린 기기는 다시 찍기만 하면 됨
- **상태 표시** — 상단에 "연결됨" / "상대 기기를 기다리는 중"
- 아이폰은 사파리와 홈 화면 앱의 저장 공간이 달라서, 홈 화면 앱을 처음 열 때 코드를 한 번 입력

### 2. 메시지
- **텍스트** — 말풍선 누르면 복사, 링크는 눌러서 바로 열기
- **카톡식 말풍선** — 같은 사람·같은 분 메시지는 묶이고 시간은 옆에
- **PC 입력** — Enter 보내기, Shift+Enter 줄바꿈
- **안 읽은 메시지** — 다른 탭을 보고 있으면 탭 제목에 숫자
- **놓친 메시지 다시 받기** — 화면이 꺼졌거나 앱을 닫아 둔 사이 온 메시지·사진·대화 지우기를 **2분 안에** 다시 열면 빠짐없이·순서대로·한 번씩 받음

### 3. 사진·동영상·파일
- **+ 버튼** — 📷 앨범(갤러리) / 카메라(휴대폰) / 파일
- **보내기 전 미리보기** — 고른 것 확인·✕로 빼기
- **화질** — 기본 일반 화질(긴 변 2048px로 줄여 빠르게), "원본 화질" 켜면 그대로
- **앨범** — 여러 장은 바둑판 말풍선 하나로 묶이고 "모두 저장"
- **크게 보기** — 사진 누르면 전체 화면, 옆으로 넘기기·저장
- **PC** — 끌어다 놓기, Ctrl+V 캡처 붙여 넣기
- **안드로이드** — 갤러리에서 "공유 → Tunnel"로 바로 보내기 (설치한 앱)
- **크기** — 파일 하나 100MB까지, 종류 무관 (8MB 조각으로 나눠 올림)
- **끊겨도 이어서** — 업로드 중 연결이 끊기거나 서버가 재시작되면 자동으로 최대 5번 다시 시도하고, 받은 데까지 건너뛰어 이어서 올림 (같은 사진이 두 번 가지 않음)

### 4. 기록 안 남기기 (앱 기본)
- 대화는 어디에도 저장 안 됨 (새로고침·창 닫기 시 사라짐)
- 사진·파일은 서버 메모리에 10분만 있다가 자동 삭제
- 놓친 메시지용 보관도 서버 메모리에 2분만 (대화 지우기·둘 다 나가면 즉시 삭제)
- 둘 다 앱을 닫으면 방·파일 즉시 사라짐 (연결만 끊긴 경우 30초 기다림)
- **🗑 휴지통** (헤더) — 누르는 즉시 양쪽 화면 대화 + 서버 파일 삭제
- 사진·동영상은 브라우저 캐시에도 안 남음 (`Cache-Control: no-store`)
- 서버 로그에 방·코드·열쇠·대화를 남기지 않음

### 5. 흔적 지우기 확장 프로그램 (PC 크롬·엣지, 현재 1.2.0)
웹사이트는 보안상 브라우저 방문 기록을 지울 수 없어서 `extension/` 의 확장 프로그램이 대신 지운다.
- **자동 삭제** — 앱을 열거나 "text tunnel"을 검색하는 즉시 그 기록 삭제 (끌 수 있음)
- **지금 지우기** — 방문 기록 + 관련 검색 기록(구글·빙·네이버·다음) + 다운로드 목록 + 캐시
- **완전 정리 단축키** (기본 Ctrl+Shift+9) — 양쪽 대화·서버 파일 삭제 → 연결 정보·사이트 데이터 삭제 → 앱 창 닫기. 다시 쓰려면 QR 재연결
  - 앱 창이 앞에 있으면 앱이 직접 키를 받아 항상 동작. 앱이 뒤에 있을 때 안 되면 다른 프로그램이 같은 키를 쓰는 것 → `edge://extensions/shortcuts` 에서 Ctrl+Shift+8 처럼 다른 숫자로
- 다른 사이트 기록·다른 검색·연결 열쇠(지금 지우기의 경우)는 건드리지 않음
- **설치**: 앱 메뉴 → 방문 기록 지우기 → zip 받기 → 압축 풀기 → `edge://extensions`(또는 `chrome://extensions`) → 개발자 모드 → 압축 풀린 폴더 로드. **앱을 설치한 브라우저에 설치**해야 함
- **자동 업데이트 안 됨** — 새 버전이 나오면 앱 화면에 안내. zip 다시 받아 기존 폴더에 덮어쓰고 확장 페이지에서 새로고침

### 6. 앱 메뉴 (⋯)
새 기기 연결(QR·코드) · 대화 지우기 · 방문 기록 지우기(PC) · 앱으로 설치 · 이 기기 이름 바꾸기 · 연결 해제

### 7. 기타
- 휴대폰·PC 같은 화면, 다크 모드 자동
- 홈 화면·바탕화면 아이콘으로 설치 (PWA). 작업 표시줄 아이콘이 싫으면 `edge://apps` 에서 '창으로 열기' 끄기
- 서버를 업데이트하면 앱을 다시 열 때 자동 적용 (확장만 수동)
- 무료 서버가 잠들어 있으면 "서버 깨우는 중" (최대 1분)

## 실행

```
node server.js          # http://localhost:8787
```

Windows 에서는 `start.cmd` 더블클릭. 화면만 보려면 `http://localhost:8787/#demo` (서버 연결 없이 예시 대화, `#demo-tray` `#demo-qr` `#demo-ext` 등 장면 지정 가능).

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 포트 (Render 는 자동 지정) |
| `MAX_MB` | 100 | 파일 하나 최대 크기 |
| `MEM_MB` | 300 | 서버가 들고 있는 파일 전체 최대 크기 |
| `MAX_ROOMS` | 50 | 동시에 열려 있을 수 있는 연결 수 |
| `STALE_SEC` | 90 | 살아 있음 신호가 이만큼 없으면 꽉 찬 방에서 자리를 내줌 |
| `REPLAY_SEC` | 120 | 끊겼다 다시 연결한 기기에 다시 보내 줄 최근 메시지 보관 시간 (메모리) |

## 시험

```
node tests/pair.test.js http://localhost:8787                   # 짝 맺기 16항목
node tests/upload.test.js http://localhost:8787                 # 업로드 이어 올리기 9항목
SKIP_RL=1 node tests/pair.test.js https://text-tunnel.onrender.com  # 실제 서버 (IP 차단 시험 제외)
STALE_SEC=3 node server.js   # 다른 터미널에서 띄운 뒤
node tests/rejoin.test.js http://localhost:8787                 # 유령 자리 정리 6항목
REPLAY_SEC=3 node server.js  # 다른 터미널에서 띄운 뒤
node tests/replay.test.js http://localhost:8787                 # 놓친 메시지 다시 받기 10항목
```
