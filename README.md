# text-tunnel

> 만든 날짜: **2026-10-20** (저장소 생성) · 개발 시작 2026-10-14

DB 없이 방 이름·비밀번호로 들어가 기기끼리 텍스트·사진·동영상을 주고받는 개인용 메신저(PWA).

- 같은 방에 접속해 있는 기기끼리만 주고받는다. 서버는 디스크에 아무것도 쓰지 않는다.
- 모두 나가면 방이 대화·파일과 함께 사라진다 (연결만 끊긴 경우 30초 기다림).
- 사진·동영상은 8MB 조각으로 올리고, 서버 메모리에 10분만 둔다.
- 의존성 없음 (Node 기본 모듈만 사용).

## 실행

```
node server.js          # http://localhost:8787
```

Windows 에서는 `start.cmd` 더블클릭.

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 포트 |
| `MAX_MB` | 100 | 파일 하나 최대 크기 |
| `MEM_MB` | 300 | 서버가 들고 있는 파일 전체 최대 크기 |
| `MAX_ROOMS` | 50 | 동시에 열 수 있는 방 수 |

화면만 보려면 `http://localhost:8787/#demo` (서버 연결 없이 예시 대화).

## Render 배포

New → Web Service → 이 저장소 선택

- Runtime: Node
- Build Command: (비움)
- Start Command: `node server.js`
- Instance Type: Free

무료 플랜은 15분 동안 접속이 없으면 잠들고, 다음 접속 때 30초~1분 뒤 깨어난다.
