# text-tunnel

> 만든 날짜: **2026-10-20** (저장소 생성) · 개발 시작 2026-10-14
> 작업 내역·결정 이유·시험 기록: [docs/WORKLOG.md](docs/WORKLOG.md)

DB 없이 내 PC와 휴대폰을 한 번 짝지어 두고, 앱만 열면 텍스트·사진·동영상·파일을 주고받는 개인용 메신저(PWA).

- 처음 한 번 PC에 뜬 QR을 휴대폰으로 찍거나 6자리 코드를 입력해 짝을 맺는다. 코드는 5분·1회용.
- 짝을 맺으면 두 기기가 같은 비밀 열쇠를 각자 브라우저에 보관하고, 앱을 열 때마다 그 열쇠로 자동 연결한다.
- 한 연결에는 최대 2대. 서버는 열쇠·대화를 디스크나 로그에 남기지 않는다.
- 둘 다 닫으면 메시지·파일이 바로 사라진다 (연결만 끊긴 경우 30초 기다림).
- 아이폰은 사파리와 홈 화면 앱의 저장 공간이 달라서, 홈 화면 앱을 처음 열 때 코드를 한 번 입력한다.
- 사진·동영상은 8MB 조각으로 올리고, 서버 메모리에 10분만 둔다.
- 의존성 없음 (Node 기본 모듈만 사용).

## 방문 기록 지우기 (크롬·엣지 확장)

웹사이트는 브라우저 방문 기록을 지울 수 없어서 `extension/` 의 작은 확장 프로그램이 대신 지운다.

- 앱 메뉴 → **방문 기록 지우기** 에서 zip 다운로드와 설치 순서를 안내한다 (`/text-tunnel-cleaner.zip`, 서버가 시작할 때 `extension/` 을 묶음).
- 앱을 열 때마다 이 주소의 방문 기록을 바로 지운다 (끌 수 있음). **지금 지우기** 는 쌓인 기록 + 캐시를 한 번에 지운다.
- 연결 열쇠(localStorage)와 다른 사이트 기록은 건드리지 않는다.
- **Ctrl+Shift+9 완전 정리** (1.1.0~, 크롬 전체 단축키): 열린 앱에 양쪽 대화·서버 파일 지우기와 방 나가기를 시키고, 앱 창을 닫고, 이 사이트의 데이터(연결 열쇠 포함)·캐시·방문 기록을 지운다. 다시 쓰려면 QR로 새로 연결. 단축키는 `chrome://extensions/shortcuts` 에서 바꿀 수 있다.
- 확장은 자동 업데이트되지 않는다. 버전이 바뀌면 zip 을 다시 받아 압축을 풀고 확장 페이지에서 새로고침.
- 사진·동영상은 서버가 `Cache-Control: no-store` 로 보내 브라우저 캐시에 남지 않는다.

## 실행

```
node server.js          # http://localhost:8787
```

Windows 에서는 `start.cmd` 더블클릭.

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 포트 |
| `MAX_MB` | 100 | 파일 하나 최대 크기 |
| `MEM_MB` | 300 | 서버가 들고 있는 파일 전체 최대 크기 |
| `MAX_ROOMS` | 50 | 동시에 열려 있을 수 있는 연결 수 |

화면만 보려면 `http://localhost:8787/#demo` (서버 연결 없이 예시 대화).

## Render 배포

- Runtime: Node

- Start Command: `node server.js`
- Instance Type: Free
