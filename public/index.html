앱으로 설치하면 다음부터 아이콘만 누르면 열려요

브라우저 메뉴 ⋮ → 앱 설치 또는 홈 화면에 추가

메뉴에 설치가 없다면 카메라·렌즈 앱 안의 미니 브라우저로 열린 거예요. 여기서는 연결이 저장되지 않으니 Chrome에서 이 주소를 열고 PC 화면의 QR을 다시 찍어 주세요.

  1. 아래쪽 공유 버튼 누르기
  2. 홈 화면에 추가 누르기
  3. 홈 화면의 Tunnel 아이콘 열기
  4. PC에서 새 기기 연결을 눌러 나온 코드를 한 번만 입력
원격 화면 연결 중…
접속 PIN 을 입력하세요

이 PIN 은 원격 PC 의 주인이 에이전트에서 정한 번호예요. 번호를 모르면 볼 수 없어요.

원격 PC 가 아직 안 보여요

보고 싶은 PC 에서 앱 메뉴 → 이 PC 원격 허용 켜기 를 따라 에이전트(remote-agent.exe)를 켜 두세요.

이 PC 원격 허용 켜기 확인하는 중…

이 PC 를 다른 PC 에서 보고 조종하려면 에이전트 프로그램을 이 PC 에서 켜 둬야 해요. 브라우저만으로는 다른 프로그램의 마우스·키보드를 대신 눌러 줄 수 없어서 작은 프로그램이 필요해요.

  1. 에이전트 받기

    압축을 풀면 바로 실행할 수 있어요 (Windows 에 들어 있는 컴파일러로 처음 한 번 자동 빌드 — 따로 설치할 것은 없어요).

    에이전트 받기 (zip)
  2. 연결 코드 만들기

    에이전트가 이 앱과 같은 짝 열쇠를 받는 6자리 코드예요. 5분 안에 한 번만 쓸 수 있어요.

    압축 푼 폴더에서 명령 프롬프트로 실행

  3. 트레이 아이콘에서 설정

    시계 옆에 방패 아이콘이 생겨요. 우클릭해서:

    • 접속 PIN 설정… — 먼저! 정하기 전에는 아무도 이 PC 를 볼 수 없어요
    • 원격 조종 허용 — 마우스·키보드까지 쓰려면 (기본은 보기만)
    • Windows 시작 시 자동 실행 — PC 를 켤 때마다 자동으로 켜져요

켜져 있는 동안 누가 보면 화면 맨 위에 빨간 띠가 떠요. 다른 PC 에서는 앱 메뉴 → 원격 화면 보기 로 들어가 PIN 을 입력해요.

방문 기록 지우기

웹사이트는 브라우저 방문 기록을 직접 지울 수 없어서, 작은 크롬 확장 프로그램이 대신 지워요. 엣지에서도 돼요.

설치됨

새 버전 이 있어요. 확장은 자동 업데이트가 안 돼서 직접 바꿔야 해요.
① zip 다시 받기 → ② 압축을 풀어 기존 text-tunnel-cleaner 폴더에 덮어쓰기 → ③ 확장 페이지에서 새로고침 ↻ → ④ 아래 '설치했어요 · 다시 확인'

Ctrl+Shift+9 완전 정리

이 단축키를 누르면 양쪽 대화·서버 파일을 지우고, 연결을 해제하고, 이 사이트의 데이터·캐시·방문 기록을 지운 뒤 앱을 닫아요. 다시 쓰려면 QR로 새로 연결해요.

앱 창이 앞에 있으면 항상 동작해요. 앱 창이 뒤에 있을 때 안 되면 다른 프로그램이 같은 키를 쓰고 있는 거예요. 크롬에 같은 확장이 있다면 지우고, edge://extensions/shortcuts 에서 Ctrl+Shift+8 처럼 다른 숫자로 바꿔 보세요.

아직 설치되지 않았어요

확장 프로그램 받기 (.zip)
  1. 받은 text-tunnel-cleaner.zip을 마우스 오른쪽 → 압축 풀기
  2. 새 탭 주소창에 chrome://extensions 붙여 넣기
  3. 오른쪽 위 개발자 모드 켜기
  4. 압축해제된 확장 프로그램을 로드합니다 → 압축 푼 text-tunnel-cleaner 폴더 선택
  5. 아래 버튼을 누르면 설치됨으로 바뀌어요

Text Tunnel 주소의 기록과 캐시만 지우고, 다른 사이트 기록과 연결 정보는 건드리지 않아요. 회사 PC 정책으로 개발자 모드가 막혀 있으면 설치할 수 없어요.
