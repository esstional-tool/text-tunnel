앱으로 설치하면 다음부터 아이콘만 누르면 열려요

브라우저 메뉴 ⋮ → 앱 설치 또는 홈 화면에 추가

메뉴에 설치가 없다면 카메라·렌즈 앱 안의 미니 브라우저로 열린 거예요. 여기서는 연결이 저장되지 않으니 Chrome에서 이 주소를 열고 PC 화면의 QR을 다시 찍어 주세요.

  1. 아래쪽 공유 버튼 누르기
  2. 홈 화면에 추가 누르기
  3. 홈 화면의 Tunnel 아이콘 열기
  4. PC에서 새 기기 연결을 눌러 나온 코드를 한 번만 입력

방문 기록 지우기

웹사이트는 브라우저 방문 기록을 직접 지울 수 없어서, 작은 크롬 확장 프로그램이 대신 지워요. 엣지에서도 돼요.

설치됨

Ctrl+Shift+9 완전 정리

앱 창이 뒤에 있어도 이 단축키를 누르면 양쪽 대화·서버 파일을 지우고, 연결을 해제하고, 이 사이트의 데이터·캐시·방문 기록을 지운 뒤 앱을 닫아요. 다시 쓰려면 QR로 새로 연결해요.

아직 설치되지 않았어요

확장 프로그램 받기 (.zip)
  1. 받은 text-tunnel-cleaner.zip을 마우스 오른쪽 → 압축 풀기
  2. 새 탭 주소창에 chrome://extensions 붙여 넣기
  3. 오른쪽 위 개발자 모드 켜기
  4. 압축해제된 확장 프로그램을 로드합니다 → 압축 푼 text-tunnel-cleaner 폴더 선택
  5. 아래 버튼을 누르면 설치됨으로 바뀌어요

Text Tunnel 주소의 기록과 캐시만 지우고, 다른 사이트 기록과 연결 정보는 건드리지 않아요. 회사 PC 정책으로 개발자 모드가 막혀 있으면 설치할 수 없어요.
